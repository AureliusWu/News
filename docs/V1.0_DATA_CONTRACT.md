## 阅读与原文

- 保留原 schema 1、数值文章 ID、API 字段/游标；追加稳定标识不替换旧 id。
- 原文 `published_at` 不以抓取时间替代；generated_at、来源 checked_at 和发布时间区分。
- 分享仅 q/region/category/language/source 白名单；收藏/来源/事件返回保留白名单 query。
- 收藏以原文 URL 为键，summary 可为 null；文本插值不渲染来源 HTML。500 收藏、5000 已读上限，按 BASE_URL 隔离；跨标签页重读有效存储，损坏数据不覆盖当前有效状态。
- 导出 schema 1，含 bookmarks/exported_at，不含已读、凭据或浏览器信息。导入限 2 MiB/500 条，全部验证后合并；重复 URL 保留已有记录，拒绝脚本协议、认证信息 URL、无效日期。
- 存储失败提示仅本次有效，不阻断阅读；已读是主动标记，不证明阅读全文，不提供跨设备同步。
- 来源 notes 保留原始证据；无近期条目、超时、403、404 不混为同一故障，不产生媒体信誉分数。

## M2 快照扩展（候选已实现）

| 字段 | 规则 |
| --- | --- |
| article_id | `a_` + 规范原文 URL 的 SHA-256 前 24 位，兼容旧数值 id |
| publisher_id | `p_` + 规范发布机构名称摘要；同机构多订阅源只计一次，不证明机构间内容独立 |
| event_id | `e_` + 初始文章锚点摘要；注册表保留文章映射和锚点，新文章或锚点不在当前快照中不改变已有 URL |
| snapshot_id | 不可变 24 位十六进制代号，绑定生成时间和内容摘要 |
| events_file/source_health_file | 同目录 `events.<代号>.json`、`source-health.<代号>.json`；provider 只接受限定文件名和同代报告，拒绝跨目录和跨代 |
| method_version | `lexical-complete-link-v1`，事件结果记录输入文章、publisher_ids、数量和原文首尾时间 |

方法使用标题、时间、语种，以及可用且不冲突的来源摘要作辅助证据，保守同语种 48 小时时窗；数字/动作冲突拒合并，采用 complete-link 与持久种子锚点防止桥接。没有处理全文或跨语种聚合，不保证语义完整。候选 acceptance_status 为 `awaiting-human-evaluation`。

保留最多三代快照；事件注册表最多90天、5000事件、10000文章映射、4MiB。损坏/不兼容注册表不自动重置；旧生产无代号的legacy允许明确首次bootstrap。2026-10-01已实现显式审核合并：旧ID作为直接别名保留，最多5000别名，不允许循环/链或指向不存在的事件，目标淘汰时别名也结束保留。正常采集不调用迁移；已有显式审核拆分工具，要求完整保留成员证据；第一组保留旧URL，其余组生成确定性新ID，不创建一对多别名，正常采集不自动纠错。没有公开部署验收，不能宣称永久无期限深链。

旧signature和method_version保持v1，新增matcher_version=`title-summary-v4`。审核迁移记录实际label_origin和reference，AI不改成human。别名出现在同代事件索引；UI提示历史链接已合并。代码归档补充event_matcher_version和event_alias_schema_version=1，无别名能力的旧归档重新完整构建。本轮仅隔离候选验证，原注册表/线上数据未替换。

## Provider 与发布

`SnapshotProvider` 与 `ApiProvider` 使用显式 request/snapshot/asset 接口，生产不安装全局 fetch 拦截。快照事件和来源报告同代读取，缓存最多六个报告，命名空间隔离于 `/News/`。API 原有新闻接口保留；本轮 API 事件快照明确报“不可用”，没有伪造成功响应或新增后台路由。

`release.json` 记录 version/stage/formal_release/source_revision/built_at/data_schema_version，并追加 base_path、event_method_version、app_bundle_sha256、asset_count。候选 formal_release=false。有界代码 zip <=2 MiB、展开 <=4 MiB、<=256 文件，校验摘要、路径和必需入口；不包含新闻 data。

计划任务可从上次成功发布的 Pages 恢复兼容代码和持久状态，复用时保留实际代码构建时间/提交号；更新新闻时间不冒充代码重新构建。推送构建新代码。兼容性/完整性失败阻止发布，不能静默部署混合版本。本流程尚未公开运行验收。

## 缺失、过期与评估

未知值为 null/未知，过期时间不改写。收藏长期保留历史发布时间，但不纳入新鲜新闻门禁。人工标注需同 snapshot_id/content_sha256 和具名审核者；至少 200 对明确标签、精确率 >=95%，召回率和正样本量独立披露。合成测试、AI 标注和分层抽样结果不能冒充人工或总体统计质量。

用户授权的代理语义审阅另存 `ai-labels.json` / `ai-evaluation.json`，明确 `label_origin=ai`、`independent_gold_standard=false`，逐对记录依据和定性把握；不修改原人工包或将AI标签送入人工门禁。本次240对中237对明确、3对不确定，结果仅作开发诊断，不校准为总体概率或正式人工证据。
