## Matching safeguards

- Summary support is English-only and requires supplied summaries on both sides. Missing, oversized, or ambiguous same-anchor summaries abstain.
- Support requires substantial title overlap, shared action and named-subject evidence, and substantial rare-token overlap in summaries. It does not simply lower the existing matching threshold.
- Existing title-number, language, time-window, negation, country/person, ordinal, and complete-link guards remain in the matching path.
- Added exclusive opposing-action checks for allow/reject, appoint/resign, resume/stop, and win/lose.
- Summaries are used only in the current comparison context, not added to durable raw anchors. If an old anchor is absent from the available source material, no summary is invented or borrowed for it.
- Existing article-to-event mappings remain pinned. Normal collection does not silently merge old event IDs.
- Explicit reviewed migration receives the same comparison context and still requires pairwise compatibility. Its output remains isolated in `artifacts/v1-m2-summary`.
- Grouping related coverage does not establish which source's disputed numbers or claims are correct. Source-specific values must remain attributable.
