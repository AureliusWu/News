## 产品与约束

中文优先、来源透明、按事件组织的全球新闻阅读器。免费核心采用 GitHub Pages + Actions + 有界 JSON 快照；不依赖 Docker、常开个人电脑或公网实时 API。保留原生 FastAPI/PostgreSQL 路线，不做本轮数据库迁移。原文标题、摘要和来源署名不伪装为中文译文或 AI 全文分析。

2026-10-01最新进度：M2改写匹配、显式审核合并和旧ID别名已实现并在隔离候选回归。原AI开发包召回率6.67% ->46.67%，仍16对漏合并；100前端、70后端、24项事件/评分/归档测试及构建通过。11个旧深链实测通过。没有重置原状态、覆盖线上数据或宣称人工门槛通过，暂不进入M3。详见 [V1.0_M2_RECALL_FIX.md](V1.0_M2_RECALL_FIX.md)。
