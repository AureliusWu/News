# Global News V0.1 HANDOFF

## 已完成

- 已按 Global News Master Prompt v0.1.0 完成骨架搭建。
- 完成后端 FastAPI、前端 Vue 3、PostgreSQL、Docker 与 PWA 基础配置。
- 已实现健康检查接口与前端首页展示健康状态。
- 已补齐项目文档与环境配置，并输出当前交付文件。

## 当前架构

- `backend/`: FastAPI + SQLAlchemy + Alembic 初始化。
- `frontend/`: Vue 3 + TypeScript + Pinia + Router + Tailwind + vite-plugin-pwa。
- `postgres`: docker compose 中启动。
- `config/`: 新闻源与分类/地区配置占位文件。
- `worker/`: 预留未来 V0.2 worker 脚本。
- `infra/nginx/default.conf`: 前端 nginx 基础路由配置。
- `docs/`: 需求、API、架构与交付说明。

## 启动方式

1. `cp .env.example .env`
2. `docker compose up --build`
3. 打开：
   - 前端：http://localhost:8080
   - 后端健康：http://localhost:8000/health

## 测试方式

- 后端：
  - `cd backend`
  - `pytest`
- 前端：
  - `cd frontend`
  - `npm test`

## 环境变量

`.env.example` 至少包含：

- `APP_ENV`, `APP_NAME`, `APP_VERSION`
- `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_HOST`, `POSTGRES_PORT`
- `DATABASE_URL`
- `BACKEND_HOST`, `BACKEND_PORT`
- `VITE_API_BASE_URL`
