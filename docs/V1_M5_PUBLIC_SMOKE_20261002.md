下载新候选整包时，`scripts/restore-pages-artifact.py` 报 `Paired snapshot and report generations differ.`。
调查发现当前健康报告采用 `snapshot_id` + `checked_at`，新增恢复/观测工具却要求其具有新闻快照的 `generated_at` 和 `content_sha256`；新增公网整包烟测脚本还误用了下划线报告文件名。
这是本轮新增验收工具的缺陷。六项恢复测试只覆盖了旧格式及其拒绝路径，未覆盖当前实际报告格式；本地测试数不能据此宣称新候选整包恢复通过。
