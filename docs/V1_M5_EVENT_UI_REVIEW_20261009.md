本轮查询到的标签页能力仅为 `pageAssets` 和 `webmcp`，未提供离线切换能力，见 [实际能力清单记录](evidence/v1-m5-20261009-events-ui/browser-capabilities.json)。不通过篡改 `navigator.onLine`、伪造离线 UI、仅检查 Service Worker 文件存在或把刷新成功当成离线通过。
