# V0.2 UI 简体中文化

## 范围

用户确认默认简体中文方案，保留 Global News 英文品牌，不增加语言切换或国际化依赖。
通用文案及地区、分类、语言标签集中在 `frontend/src/locales/zh-CN.ts`。

- 中文化导航、首页分类、搜索筛选、加载和空结果状态、错误和重试提示。
- 中文化新闻卡片的分类、地区、阅读原文提示和相对时间。
- 中文化快照加载、缓存、延迟、来源可用数量及刷新按钮。
- 关于页说明新闻来源、原文版权、更新方式、时间含义和离线限制。
- 页面语言标记为 `zh-CN`；新闻标题和摘要保留原语言标记。
- 保留现有视觉风格和中文字体回退，仅加宽时间栏以容纳中文时间。

## 数据和运行边界

- 不翻译新闻标题、摘要和媒体名称，不引入 AI 翻译。
- 只映射显示名称，筛选参数、来源 ID、API 路径和数据结构保持不变。
- 未知地区、分类和语言代码原样显示，不隐瞒未知值。
- 不改 RSS 采集、排序、分页、缓存有效期或发布门槛。
- 相对时间使用中文；完整时间按浏览器本地时区显示并包含时区。
- 原文发布时间仍来自 `published_at`；快照更新时间仍来自 `generated_at`。
- 原始时间字段不被翻译、覆盖或重新生成。
- 关于页按 API / snapshot 构建模式分别解释更新方式。
- 中文化不新增中英切换，不涉及 V0.3 功能；发布前另行获准修正 PWA 子路径及补充构建产物门槛，见 `PWA_BASE_PATH_FIX.md`。

## 验收边界

本文件记录实现范围，不代表测试、构建、浏览器或公网验收通过。
用户已批准同步测试断言并运行前端测试和构建；断言已同步并补充中文标签、原始筛选代码、原文保留、时间和模式说明等覆盖，实际执行结果以本次测试与构建记录为准。
