## Checks still executed before publication

The release work will still execute current frontend/unit/type/build checks,
backend and snapshot tests in their stated CI scope, browser online/offline/upgrade
cases, and a corrected same-input performance diagnostic. Results and raw failures
are to be recorded separately. Build correctness, version binding and actual
public accessibility are not inferred from this approval or a Git push.

Chromium could not start with its sandbox. Its Lighthouse custom configuration
also overrode the desktop preset. Those records are retained and are not counted
as a passed desktop performance cohort.
