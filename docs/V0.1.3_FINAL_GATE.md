## Alembic Warning Investigation

- Warning 原文摘要：
  - `RuntimeWarning: coroutine 'run_migrations_online.<locals>.do_run_migrations' was never awaited`
  - 位置：`/app/migrations/env.py:44`
- 来源定位：
  - 来自我们自己的 `backend/migrations/env.py`。
  - `connection.run_sync(...)` 里接收了 async 回调，返回协程对象未被 await。
- 修复内容：
  - 已将 `do_run_migrations` 从 `async def` 改为 `def`（同步回调）。
- 重跑结果：
  - `docker compose exec backend alembic current`
  - `docker compose exec backend alembic upgrade head`
  - `docker compose exec backend alembic current`
  - 以上命令不再出现该 RuntimeWarning。
- 正确性影响：
  - 无阻塞；仅是 SQLAlchemy 迁移回调的 await/同步契约修正，保持 migration 流程行为不变。
