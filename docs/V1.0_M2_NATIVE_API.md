# M2 native event API candidate

Status: implementation candidate, not a V1.0.0 release. Native PostgreSQL
production acceptance, independent human evaluation, and the seven-day gate
are not implied by these endpoints or by synthetic SQLite tests.

## Scope

- Database news and enabled sources remain authoritative; no Pages data fallback.
- No database migration, new dependency, Docker requirement, or paid service.
- The completed `worker:last_sync_at` is the data timestamp, never request time.
- Three immutable, digest-bound generations and the stable event registry are
  stored in an explicitly configured persistent directory. Back up this directory
  with the database. An ephemeral host directory does not establish durability.
- Default-off: missing configuration, expired/invalid timestamps, corrupt state,
  or contention returns 503 with retry guidance. Missing historical reports are
  404. The service never silently resets damaged history.
- Native projection readiness is not the Pages feed-coverage acceptance gate.
  At most 2000 recent database articles are projected; truncation is explicit.

## Configuration

Set `NATIVE_EVENT_STORE_PATH` to an absolute persistent directory owned by the
backend service, for example `/var/lib/news/native-events` on a configured host.
Do not point multiple unrelated database installations at the same directory.
For local tests, use a dedicated directory under ignored `artifacts/`.

## Endpoints and binding

- `GET /api/v1/snapshot`: native articles and public source metadata, stable IDs,
  actual sync timestamp, event/report names, generation, and SHA-256.
- `GET /api/v1/events`: event index for the current native generation.
- `GET /api/v1/events/{event_id}`: canonical ID, alias resolution, source-linked
  original articles in publication order; no invented factual summary.
- `GET /api/v1/snapshots/{generation}/{name}`: only the bound events/source-health
  report for one of the three retained generations. No arbitrary file access.
- The API provider requests these native routes directly and checks generation,
  timestamp, digest, MIME, and report bounds. Snapshot Pages mode is unchanged.

## Recovery

OS file locks protect pointer rotation across workers; a process lock serializes
async requests. Each generation is sealed before atomic pointer replacement.
Restore a known paired directory/database backup after corruption; do not delete
the registry to make the health gate green. A generation outside the retained
publication window is explicitly unavailable, not remapped to an unrelated event.
