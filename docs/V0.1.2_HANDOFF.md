## 3. 最终架构

- Browser: Vue3 SPA（Vite）
- Frontend Serve: 前端容器 `frontend`（Nginx + `frontend/Dockerfile`）
- Backend: FastAPI + SQLAlchemy async + Alembic（容器 `backend`）
- Database: PostgreSQL 16（容器 `postgres`）
- Reverse Proxy: 同一个前端 Nginx 的 `/api/` 反代规则
- PWA: `vite-plugin-pwa` 打包 manifest 与 service worker
- 数据流:
  - Browser
    - GET `/` -> 前端 Nginx -> SPA
    - GET `/api/v1/health` -> 前端 Nginx `/api/` -> backend -> PostgreSQL

## 4. 环境策略

- Docker DB: `DATABASE_MODE=docker`，后端走 `DATABASE_URL_DOCKER`
- 本机 DB（本地开发）: `DATABASE_MODE=local`，优先 `DATABASE_URL_LOCAL`，回退 `DATABASE_URL`
- Frontend API 路径: `/{BASE_URL}api/v1/health`（默认 same-origin）
- Nginx Proxy: `infra/nginx/default.conf` 的 `/api/` 反代到 `backend:8000`
- Vite Proxy: 开发环境 `/api` 代理到 `127.0.0.1:8000`
- CORS: 白名单配置项 `CORS_ALLOWED_ORIGINS`，不再使用通配符
