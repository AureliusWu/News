# M4 可选 AI：关闭路径验收

日期：2026-10-02；候选：`0.9.0-alpha.1`，非 V1.0 正式发布。

## 决策与边界

按已批准方案，在没有已确认免费额度时关闭内容生成，不创建账户、不自动付费、不向前端放置模型密钥。
本阶段采用关闭出口，不声称已实现在线翻译或逐事实 AI 摘要。原文仍是阅读依据。
此前经用户接受的 M2 AI 评估出口，仅用于冻结、版本绑定的事件评估，不是线上内容生成，也不是人工金标。

## 已实现

- `backend/config/ai_features.json` 显式关闭内容生成、翻译和摘要；费用、请求和缓存上限均为零。
- `scripts/ai-feature-policy.mjs` 在构建时拒绝启用标志、非零预算、缺失防护或不符合契约的配置。
- `scripts/write-release.mjs` 将关闭策略和源代码版本写入发布元数据，仍保持 `formal_release: false`。
- 原文切换、事实出处和不可信新闻文本边界保留为未来启用前必须满足的契约，不以开关代替功能实现。

## 验收

AI 关闭策略的两项 Node 回归通过；完整发布门禁测试共九项通过。
本轮没有调用外部内容生成模型、产生付费请求或新增依赖。重新启用必须另行证明配额、费用上限、缓存、出处及重大事实错误门禁。

结论：**M4 关闭出口通过；AI 内容生成功能未发布。**
