只使用新目录内合成 SQLite 数据，不使用生产数据库。4 个合成发布机构，数据库 2,001 篇全部符合完成标记，API 返回 2,000 篇，并标记达到上限；事件为 1,962 个，热度可展示事件为 1,312 个。

首次 `/api/v1/snapshot` 29,184.55 ms；事件 519.04 ms；趋势 614.78 ms；三次暖快照 585.37 / 552.69 / 542.45 ms。
快照、事件、趋势、详情、版本绑定资产、`/News/events` 均为 HTTP 200；未带 API 前缀的 `/trends` 为 404。
全量 1,962 个事件的 Python/TypeScript 趋势结果严格相等。

这是关闭原 45 秒超时的本地边界证据，**不是生产性能 SLA 通过**。首次 API 约 29 秒仍偏慢；本轮浏览器访问的是已生成投影，尚未接受前端首次冷投影体验。
